# cryptograph

A public collection of concise, rigorous cryptography learning materials.

## Modules

### [theory](theory/)

The mathematical path from finite fields and discrete logarithms through
elliptic curves, Curve25519, X25519, and secure protocol composition.

- [Read the theory guide](theory/README.md)
- [Open the compiled note](theory/tex/cryptograph-theory.pdf)
- [Explore the marimo notebooks](theory/notebooks/)

To work with the theory module locally:

```bash
cd theory
uv sync --dev
make check
```
