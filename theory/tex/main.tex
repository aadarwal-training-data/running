\begin{abstract}
This note builds the shortest rigorous path from modular arithmetic to X25519.
It defines the discrete logarithm problem in an arbitrary cyclic group,
instantiates it as the elliptic-curve discrete logarithm problem, derives the
Diffie--Hellman equality, and then studies Curve25519's field, subgroup,
cofactor, quadratic twist, x-only Montgomery ladder, and byte encoding. The
last section states the boundary between a scalar-multiplication primitive and
a secure authenticated protocol. Companion marimo notebooks make every small
example executable and visual.
\end{abstract}
